# learn_code

一个包含多个子项目的学习与练习仓库，涵盖前端框架、Node.js、编译原理及基础算法。

## 项目索引

| 目录 | 重点内容 | 核心技术 |
| :--- | :--- | :--- |
| [demo-ssr/](demo-ssr/) | 手写 SSR 演示 | React 18, Express, esbuild |
| [demo-next-cache/](demo-next-cache/) | Next.js 16 缓存机制 | Next.js 16, RSC, Data Cache |
| [ast/](ast/) | Babel AST 转换练习 | Babel, Node.js |
| [node-server/](node-server/) | 服务端示例 | Express, WebSocket, Streams |
| [demos/test-demo/](demos/test-demo/) | JS 概念与算法练习 | ES6+, 基础算法 |
| [examples/](examples/) | 实用工具脚本 | Node.js, CSV 处理 |
| [utils/](utils/) | 通用工具方法 | JavaScript Utils |

## 文档说明

- 每个核心子项目（如 `demo-ssr`）均包含详细的 `CLAUDE.md` 和 `AGENTS.md`。
- 根目录 `CLAUDE.md` 提供了全局的开发指引。
- 练习代码主要集中在 `demos/test-demo/` 目录下，按序号排序。
